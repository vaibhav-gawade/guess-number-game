# 🎯 Guess Number Game

A simple and interactive **Number Guessing Game** built using HTML, CSS, and JavaScript.

The goal is to guess the randomly generated number within the given range using as few attempts as possible.

## 🚀 Live Demo

👉 [Play the Guess Number Game](https://vaibhav-gawade.github.io/guess-number-game/)

## ✨ Features

* 🎲 Generates a random number for the player to guess
* 🔢 Accepts user guesses through an input field
* 💡 Provides feedback based on the user's guess
* 📊 Keeps track of previous guesses and attempts
* 🔄 Allows the player to start a new game
* 🎨 Simple and responsive user interface

## 🛠️ Technologies Used

* **HTML5** — Structure of the game
* **CSS3** — Styling and layout
* **JavaScript** — Game logic, random number generation, DOM manipulation, and event handling

## 🎮 How to Play

1. Open the [Live Demo](https://vaibhav-gawade.github.io/guess-number-game/).
2. Enter your guess in the input field.
3. Submit your guess.
4. The game will tell you whether your guess is too high, too low, or correct.
5. Use the feedback to improve your next guess.
6. Continue guessing until you find the correct number.
7. Start a new game when you want to play again.
